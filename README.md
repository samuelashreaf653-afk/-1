# بوابة الطالب الأكاديمية — نسخة تجريبية (Frontend Demo)

> **تنبيه:** هذا مشروع واجهة أمامية فقط (HTML / CSS / JavaScript) بدون Backend أو قاعدة بيانات.
> البيانات محفوظة في `localStorage` داخل المتصفح، وتسجيل الدخول والصلاحيات وسجلات الحضور **لعرض الفكرة فقط**
> وليست آمنة ولا جاهزة للاستخدام الفعلي (أي شخص يستطيع تعديل البيانات من أدوات المتصفح).

## طريقة التشغيل

1. افتح مجلد المشروع في Visual Studio / VS Code.
2. شغّل `index.html` (يفضّل عبر Live Server أو أي خادم محلي مثل `localhost` — خصوصًا لو هتجرّب **كاميرا مسح الـ QR** لأن المتصفح يطلب سياقًا آمنًا).
3. لتجربة الحضور بالـ QR افتح **تبويبين** في نفس المتصفح: واحد للدكتور وواحد للطالب (البيانات تتشارك عبر `localStorage`، والتحديث بينهما مباشر).

## حسابات التجربة (كلمة المرور للجميع: `1234`)

| الدور | اسم المستخدم | ملاحظات |
|---|---|---|
| طالب | `student` أو `20230145` | أحمد محمد علي (الحساب الأصلي) |
| طالب | `20230146` … `20230152` | طلاب تجريبيون آخرون |
| دكتور | `doctor` | أ.د. مصطفى كمال — مادة إدارة قواعد البيانات المتقدمة (3101) |
| دكتور | `doctor2` / `doctor3` / `doctor4` | هشام منصور / سامح عبد الله / طارق فؤاد |
| أدمن | `admin` | إدارة كل شيء |

اختر نوع الحساب (طالب / دكتور / أدمن) من التبويبات أعلى شاشة الدخول، أو اضغط "تعبئة بيانات التجربة تلقائيًا".

## تجربة QR الحضور

1. **الدكتور:** المحاضرات وQR الحضور ← "بدء المحاضرة" ← يظهر QR يتغير كل 20 ثانية (التسجيل مفتوح 10 دقائق).
2. **الطالب (تبويب آخر):** مسح QR للحضور ← إما كاميرا، أو **"مسح QR هذه المحاضرة (محاكاة)"**، أو لصق نص الرمز.
3. تظهر رسالة تأكيد للطالب، ويظهر الحضور عند الدكتور فورًا. تكرار المسح يُرفض كـ "مسجّل مسبقًا"، والرمز القديم أو المزوّر يُرفض.
4. الدكتور يستطيع تعديل الحضور يدويًا ويرصد الدرجات، والأدمن يستطيع تعديل أي مادة.

## الصلاحيات (محاكاة)

- **الطالب:** عرض فقط (الملف، المواد، الأساتذة، جدوله، حضوره، درجاته) + مسح QR لنفسه.
- **الدكتور:** مواده فقط — محاضرات وQR، حضور (عرض وتعديل)، درجات.
- **الأدمن:** إدارة الطلاب والأساتذة والمواد والجداول والكورسات + الحضور والدرجات لكل المواد.

التحقق من الدور يتم داخل `js/store.js` (كل عملية تفحص الدور الحالي)، لكنه يبقى داخل المتصفح فقط.

## هيكل المشروع

```
index.html
css/style.css
js/lib/qrcode.js   مكتبة توليد QR (MIT، Kazuhiko Arase) — بدون إنترنت
js/data.js         البيانات الابتدائية (الأصلية + الأساتذة والطلاب)
js/store.js        الحسابات، الصلاحيات، الحضور، الدرجات، CRUD، localStorage
js/app.js          الهيكل المشترك + لوحة الطالب (+ تبويبات الأساتذة، الدرجات، مسح QR)
js/doctor.js       لوحة الدكتور
js/admin.js        لوحة الأدمن
js/boot.js         شاشة الدخول وتشغيل المنصة
images/campus.jpg  صورة الجامعة
```

## إعادة ضبط البيانات

زر "إعادة ضبط بيانات التجربة" في شاشة الدخول أو في نظرة عامة الأدمن.

## ما يحتاج Backend حقيقي لاحقًا

حسابات بكلمات مرور مشفّرة (hash)، جلسات/JWT، فحص الصلاحيات على الخادم، قاعدة بيانات (مثل ASP.NET Core + SQL Server)،
وتوليد/تحقق رموز الـ QR على الخادم. قراءة الـ QR بالكاميرا تعتمد على `BarcodeDetector` أو مكتبة `jsQR` من CDN (تحتاج إنترنت في المتصفحات غير الداعمة).
